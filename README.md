# Bike Store SQL Analysis

A practical SQL portfolio project built using the BikeStores sample database in PostgreSQL.

The project contains SQL queries designed to practice technical interview skills and solve realistic business problems for Data Analyst roles.

## Project Goals

- Practice SQL for Data Analytics
- Develop SQL problem-solving and analytical thinking skills
- Solve realistic business and interview-style problems
- Build a portfolio for Junior Data Analyst positions
- Progress from fundamental SQL concepts to advanced analytical techniques

## Technologies

- PostgreSQL
- DBeaver
- Git
- GitHub

## Topics Covered

- ✅ Filtering & Sorting
- ✅ Aggregations
- ✅ JOINs
- ✅ Advanced JOINs
- ✅ Subqueries
- ✅ Common Table Expressions (CTE)
- ✅ Window Functions
- ✅ Business Cases
