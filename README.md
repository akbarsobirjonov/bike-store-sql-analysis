# Bike Store SQL Analysis

A collection of SQL queries built using the BikeStores sample database in PostgreSQL.

## Project Goals

- Practice SQL for Data Analytics
- Solve real-world business problems
- Build a portfolio for Junior Data Analyst positions

## Technologies

- PostgreSQL
- DBeaver
- Git
- GitHub

## Topics Covered

- ✅ Filtering & Sorting
- ✅ Aggregations
- ⏳ JOINs
- ⏳ Subqueries
- ⏳ Common Table Expressions (CTE)
- ⏳ Window Functions
- ⏳ Business Cases
